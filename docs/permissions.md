# 四種權限

| 顯示權限 | 說明 | 能力 |
| --- | --- | --- |
| primary admin | 主管理員 | 原有完整管理權限，管理操作仍需 TOTP 確認 |
| secondary admin | 副管理員 | 暫與 tester 完全相同 |
| tester | 測試員 | 完整 user 個人功能，加上使用示例資料的管理頁測試 |
| user | 用戶 | 自己出題、答題、成績、頭像、設定與私人文件 |

副管理員與測試員都不能讀取其他人的私人草稿、答卷、成績、帳號資料、日誌，不能審核、批改他人資料、管理帳號、修改配置或共享檔案。排行榜只返回本人實際資料；公開試卷與共享檔案使用限制後的測試視圖。

主管理員可將其他非主管理員帳號切換為 user、tester、secondary admin，不能透過下拉選單授予 primary admin。變更後撤銷舊會話並清理舊角色快取，目標需重新登入。

資料庫保留 admin、visitor 的既有儲存值；新副管理員儲存為 secondary_admin。權限判斷以後端為準，不由暱稱或登入 ID 推定。
