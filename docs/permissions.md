# 四种权限

| 权限 | 能力 |
| --- | --- |
| primary admin（主管理员） | 完整业务管理、账号/权限/密令/配置和删除；敏感操作需要TOTP |
| secondary admin（副管理员） | 受限业务管理：创建、复制、编辑未发布试卷，审核发布/退回，查看已提交答卷并人工批改，上传和编辑共享文件 |
| tester（测试员） | 个人功能和隔离示例管理界面，不读取真实管理资料 |
| user（用户） | 个人出题、答题、成绩、错题本、设置和私人文件 |

副管理员没有账号目录、登录ID、在线用户清单、账号停用/恢复、重置密码、权限调整、注册密令、日志、系统配置、回收站、删除或替换文件的权限。相关菜单和按钮不显示；API和数据库独立拒绝这些操作。

副管理员可发布/退回待审试卷，不能撤销发布；已发布试卷只读，可复制为新草稿，不能通过保存间接撤下发布，也不能从保存载荷中移除已有题目、选项、附件或更换已有题型。历史版本独立保留。

批改可读取所需的业务昵称和已提交答卷/附件，不读取他人未提交作答或私人转换文件。个人错题本和私人文件仍按本人UUID隔离。副管理员不要求双重验证，主管理员继续要求。

四种角色分别保留独立演示账号，昵称、登录ID和密码均为各自小写显示权限名称；只用于空数据库明确opt-in的演示，不加入正式站点。
