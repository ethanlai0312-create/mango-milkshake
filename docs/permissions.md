# 四种权限

| 权限 | 能力 |
| --- | --- |
| primary admin（主管理员） | 完整业务管理、账号/权限/密令/配置和删除 |
| secondary admin（副管理员） | 受限业务管理：创建、复制、编辑未发布试卷，审核发布/退回，查看已提交答卷并人工批改，上传和编辑共享文件；只读查看账号目录（不显示登录ID）、在线状态、操作日志及系统配置，生成和撤销注册密令 |
| tester（测试员） | 个人功能和隔离示例管理界面，不读取真实管理资料 |
| user（用户） | 个人出题、答题、成绩、错题本、设置和私人文件 |

副管理员没有账号停用/恢复、重置密码、权限调整、系统配置修改、回收站、删除或替换文件、撤销发布、查看他人登录ID的权限；账号目录、操作日志和系统配置只读，注册密令可生成和撤销。相关菜单和按钮不显示；API和数据库独立拒绝未开放的操作。

副管理员可发布/退回待审试卷，不能撤销发布；已发布试卷只读，可复制为新草稿，不能通过保存间接撤下发布，也不能从保存载荷中移除已有题目、选项、附件或更换已有题型。历史版本独立保留。

批改可读取所需的业务昵称和已提交答卷/附件，不读取他人未提交作答或私人转换文件。个人错题本和私人文件仍按本人UUID隔离。所有角色均使用登录 ID 与密码，不使用双重验证。

四种角色分别保留独立演示账号，昵称、登录ID和密码均为各自小写显示权限名称；只用于空数据库明确opt-in的演示，不加入正式站点。

账号 UUID 仅主管理员与副管理员可见；其他角色只能看到公开昵称与作者昵称。永久删除账号时，其试卷保留并显示删除前的昵称，登录身份被封禁，已注销账号不再出现在账号目录。
