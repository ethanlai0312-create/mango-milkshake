# 導航與頁面連續性

所有尺寸均使用預設隱藏的三線選單。展開後直接顯示圖標與名稱；第一級包含首頁、學習與複習、試卷創作、文件工具、管理員功能、個人帳戶，第二級列出對應功能。管理員分類只向主管理員、副管理員和 tester 顯示；tester仅可打开示例管理界面；副管理员仅可使用真实业务审核和批改入口。

抽屜不使用背景模糊，不推移主內容，支援 Escape、焦點循環、焦點返回與原生觸控滾動。動畫尊重 Reduced Motion。頁面以固定三線按鈕為起點飛入，舊頁反向飛回同一位置；過渡快照為 inert、aria-hidden，不能執行第二份業務操作。

登入後預熱程式模組及目前權限允許的常用列表。未準備好時先保留現有頁面，準備完成才切換，不用短暫的載入中頁面取代。帳號清單、配置、即時答卷與可編輯試卷不加入一般顯示快取；文件內容在開啟時向伺服器取得授權資料，再把該份資料交給真正編輯器/答卷。

預載不繞過登入、TOTP、伺服器權限或資料隔離。快取以帳號/角色/世代隔離；登出、換帳號、變更權限、資料寫入使舊資料失效。tester不预载管理资料；副管理员只预载审核和已提交业务答卷；遲到的導航或文件請求在更新 UI 前再次核對帳號。網路故障不能保證零延遲，保留原畫面並顯示可重試錯誤，而不顯示未授權快取。
