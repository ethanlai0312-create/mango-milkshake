# Security policy

Report a vulnerability privately through [GitHub private vulnerability reporting](https://github.com/ethanlai0312-create/mango-milkshake/security/advisories/new). Do not disclose account credentials, personal records, answer sheets, uploaded documents, session cookies, recovery material, or an actionable vulnerability in public issues.

Include the affected version, the smallest safe reproduction, the expected and actual result, and evidence with personal information and secrets removed. Use only your own test account and synthetic content. This policy is not authorization for service disruption, bulk password attempts, access to another person's data, or testing third-party services.

If GitHub reports that private reporting is unavailable, do not fall back to publishing sensitive details. Contact the repository owner through an already established private channel. No response time or bounty is promised.

For self-hosted copies, maintain your own reporting contact and update the deployed `/.well-known/security.txt` Canonical, Contact and Expires fields. Public example credentials are intentionally documented for fresh isolated demonstrations; never enable them on an existing private deployment.
