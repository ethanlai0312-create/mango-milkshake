# 答卷复习、错题本与统一导航

提交后的答卷可选择全部、错误、不良。服务器已批改的零分题为红色，有分但未满分为橙色，满分为绿色。尚未批改的题目独立显示为待批改，不误判成零分。筛选保留原试卷题号。

作答时的“跳转未完成题目”从最小题号开始查找；零值选项和“错误”判断答案也算有效作答，多空和配对必须填完各项。

错题本按试卷汇总本人所有历史未满分作答，可筛选零分与部分得分，分页查看原题、本人答案、参考答案、详细解析和评语。参考答案和解析沿用原试卷公开规则，未获授权时不泄露；不同账号及不同试卷版本的数据分别处理。

全尺寸使用默认隐藏的三线抽屉，分类为学习与复习、试卷创作、文件工具、管理员功能、个人账户；打开即可看图标和文字。抽屉无模糊，支持触控滚动、键盘焦点循环、Escape 关闭。主管理员才能调用管理接口；tester 与 secondary admin 仅显示隔离示例管理页面。

页面准备完成再从三线按钮位置飞入，原页面反向飞回；快速选择以最后一次为准。普通授权列表和代码模块预热，账号目录、配置和实时答卷不加入通用缓存。网络等待时保留已有页面，不展示假装已经加载完成的数据。

账号列表全局按 primary admin、secondary admin、tester、user 排序后分页。只有主管理员可看目录中的登录 ID。角色选项完整显示，窄屏改为纵向排列，超宽屏使用多列。
