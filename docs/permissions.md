# 權限說明（v01.02.000）

user 是正常出題與學習帳號。tester 繼承 user 的個人業務功能，再增加管理業務頁面的示例界面測試入口；admin 才能管理真實業務與帳號。

| 功能 | user | tester | admin |
| --- | --- | --- | --- |
| 自己的試卷、題目、匯入匯出及提交審核 | 可操作 | 可操作 | 可操作 |
| 正式答題、保存、提交及查看自己的成績 | 可操作 | 可操作 | 可操作 |
| 自己的頭像、設定、密碼及私人文件轉換 | 可操作 | 可操作 | 可操作 |
| 閱讀共享檔案與已發布內容 | 可以 | 可以 | 可以 |
| 他人的私人草稿、答卷、帳號資料及日誌 | 不可以 | 不可以 | 按管理功能存取 |
| 管理頁面的示例測試界面 | 不提供 | 可以 | 使用實際管理頁面 |
| 修改他人資料、發布審核、批改、密令和系統配置 | 不可以 | 不可以 | 按安全條件操作 |

tester 的「界面測試」包括試卷審核、帳號管理、註冊密令、人工批改、回收站、操作日誌與系統配置的示例佈局。這些頁面明確標示示例，不讀取真實管理資料，不執行管理操作；它們是展示與版面檢查入口，不是管理 API 測試授權。示例搜索只影響本頁顯示。

為保留「不能讀其他使用者資料」的限制，tester 的排行榜只顯示自己的真實記錄；不返回其他參與者的帳號、頭像或成績。

個人功能使用正常的服務端所有權檢查。tester 可修改自己的內容，不可修改其他人的內容或共享檔案。直接呼叫管理接口同樣被拒絕，不能靠改網址、按鈕或請求參數獲得權限。

admin 在帳號管理只能把非 admin 帳號切換為 user/tester，需新鮮驗證器確認。切換會撤銷舊會話，但保留伺服器上的原資料。公開 demo 帳號僅供空資料庫的隔離示範部署，不會加入原網站。
