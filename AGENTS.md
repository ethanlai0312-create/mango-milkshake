# Repository update rules

Read RELEASE_POLICY.md before any change. Update this existing repository, never create a replacement repository. Every completed update needs the padded version, changelog, Git tag, Release, tested source-only synchronization and successful CI. Add each new role to the opt-in empty-database demo seed, README and repository description using lowercase role-name credentials. Never commit user data, business content, uploads, logs, secrets, backups or private deployment history.
