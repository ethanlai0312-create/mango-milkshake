# 管理員雙重驗證器

本網站的管理員雙重驗證使用標準 TOTP 六位驗證碼，可使用 **Google Authenticator（Google 身份驗證器）**。下載應用程式後，需要先在本網站綁定，才會產生本網站的驗證碼。

## 官方下載

- Android：[Google Play](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2)
- iPhone / iPad：[Apple App Store](https://apps.apple.com/app/google-authenticator/id388497605)
- [Google 官方使用說明](https://support.google.com/accounts/answer/1066447?hl=zh-Hans)

請確認發行者為 Google。倉庫只提供官方商店連結，不重新分發安裝包。Google Authenticator 支援不登入 Google 帳號使用，產生驗證碼也不需要網絡；雲端同步由使用者自行選擇，不是本網站的必要條件。

## 在本網站綁定

1. 使用自己的 admin 帳號登入，開啟「個人設置 → 管理員雙重驗證」。
2. 點擊「綁定驗證器」，複製網站顯示的設定密鑰。
3. 在驗證器按「＋」，選擇「輸入設定密鑰」或類似選項。
4. 名稱填寫「芒果學社 admin」，貼上密鑰，類型選「基於時間」。
5. 將應用程式顯示的六位數字填回網站，點擊「驗證」。

同一部手機操作時，可複製密鑰後切換到驗證器添加，再切回網站。設定密鑰不是登入密碼；網站要求的六位數字不是短信驗證碼。日後調整權限等重要操作，使用應用程式當時顯示的驗證碼。

## 常見問題

- 驗證碼錯誤：確認選中本網站的項目，開啟手機自動日期與時間，等下一個驗證碼再試。
- 已綁定但網站再次詢問：重要操作需要重新確認，先前一次確認不能重複用於下一次操作。
- 更換手機：先在舊設備仍可使用時完成遷移，或在第二部獨立設備綁定另一個驗證器。
- 所有驗證器遺失：需由部署者在核實身分後進行伺服器端恢復，不能以任何六位數或公開示範密碼繞過。

不要將密鑰或含密鑰的畫面放入 GitHub、聊天訊息、操作日誌或公開截圖。
